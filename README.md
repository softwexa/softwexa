# Business software built around your workflow.

Softwexa develops business applications, ERP extensions and integrations for the way teams work. We bring custom software development and practical ERP expertise together, from a focused operational tool to a connected business system.

## What we're building

| Product | Focus | Explore |
| --- | --- | --- |
| **WexaFlow** | A native workflow workspace for Microsoft Dynamics 365 Finance, with flow configuration and data exploration. | [Product](https://www.softwexa.com/products/wexaflow/) · [Evaluation guide](https://www.softwexa.com/docs/wexaflow/) |
| **WexaSQL** | A native SELECT query and data exploration workspace for Microsoft Dynamics 365 Finance. | [Product](https://www.softwexa.com/products/wexasql/) · [Evaluation guide](https://www.softwexa.com/docs/wexasql/) |
| **Dolibarr themes** | Three visual themes for Dolibarr ERP & CRM, with options for connected staff workspaces. | [Theme collection](https://www.softwexa.com/products/dolibarr-theme-pack/) |

WexaFlow and WexaSQL are in development evaluation. The package, compatible Finance versions and runtime acceptance are agreed for each delivery.

## How we help

- **Dynamics 365 Finance & Operations** — consulting, X++ development and business application extensions.
- **ERP integration** — API connections and data exchange between business systems.
- **Custom software** — web, mobile and desktop applications built around your requirements.
- **Dolibarr ERP & CRM** — implementation, customization and interface themes.
- **Business automation** — workflow design, reporting and operational tools.

Start with one process, one data problem or one integration. We can help define the scope, confirm the technical requirements and plan the next step.
